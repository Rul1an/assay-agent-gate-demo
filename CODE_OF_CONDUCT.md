# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. Everyone taking part in the project, in any space it uses, is expected to uphold it.

The full text is published at the link above (and as plain text at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct.md>).

To report a concern, contact the maintainer at roelschuurkes@gmail.com. Reports are handled
confidentially, and the maintainer will respond as promptly as they can.
