# Security policy

This repository is a demonstration. It runs fully offline against a local mock MCP server, with no
real credentials, no real provider, and no real side effects. There is no production system here to
attack.

If you find a security issue in **assay** (the engine this demo is built on), please report it
privately through the [assay security policy](https://github.com/Rul1an/assay/security) rather than
opening a public issue.

If you find a problem in **this demo** that could mislead someone (for example, a scenario that looks
like it enforces something it does not), open an issue or email roelschuurkes@gmail.com. Clarity
matters here as much as code.
